# Mohsin Raza — Portfolio

React + Vite portfolio based on the original red-and-black reference designs. Styling uses Tailwind CSS; routes use React Router; animations use Motion for React and GSAP/ScrollTrigger.

## Run locally (Windows PowerShell or Command Prompt)

```powershell
cd C:\Users\mohsi\Downloads\intelligent-solutions-portfolio
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`). This project is a React/Vite website, not a Streamlit app; start it with `npm run dev` rather than `streamlit run`.

The ZIP was extracted into `design-reference/`. The cropped Home hero artwork is in `public/assets/hero-art.jpg`.
